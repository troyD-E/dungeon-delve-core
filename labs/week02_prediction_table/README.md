# Concept Lab 2 — Prediction Table

**Due Saturday.** Do this lab *before* Build 2, not after. The order is the
instruction: the lab isolates parameter passing in a small program where
nothing else is going wrong, so when Build 2 misbehaves you are debugging one
thing instead of two.

## What is here

| | |
|:--|:--|
| `prediction_table.cpp` | The program. **Do not modify it** — it is what you are predicting. |
| `PREDICTIONS.md` | Your prediction table, your reconciliation, and your closing answer. This is what you submit. |

## How to run it

From the top of the repository:

```bash
cmake --preset course-debug
cmake --build --preset course-debug
./build/course-debug/prediction_table
```

## The one rule

**Fill in the prediction table before you compile.** Once you have seen the
output you cannot predict it any more, and the lab becomes transcription. The
graded artifact is your reconciliation of where you were wrong — which only
exists if you were willing to be wrong on paper first.

You are expected to miss at least one. Several of these surprise people who
have written C++ for years.
